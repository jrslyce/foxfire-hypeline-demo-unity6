# Foxfire Arena — Clean Unity Starter

This playable project is a clean starting point for installing and testing Hypeline. It does not include the Hypeline package, prefabs, or integration scripts.

## Open and play

1. Open this project in Unity Hub with **Unity 6000.0.85f1**.
2. Open `Assets/Foxfire/Scenes/FoxfireArena.unity` and press Play.
3. Choose **Enter the Forest** for keyboard control or **AI Mode** to watch the fox play. Press Escape to pause.

The local action simulator is available with F1. It is independent of Hypeline.

## Install Hypeline

Follow the instructions supplied with your Hypeline Unity SDK to install it in this project and set up the integration. No SDK or game ID is preconfigured, so you can test the installation from the beginning.

The other Unity version is available in [the companion repository](https://github.com/jrslyce/foxfire-hypeline-demo).
